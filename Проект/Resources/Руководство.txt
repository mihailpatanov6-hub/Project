РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
Программа «Учёт репетиторских занятий»
СОДЕРЖАНИЕ
1.	Введение
2.	Главная страница
3.	Раздел «Ученики»
4.	Раздел «Расписание»
5.	Раздел «Сводка»
ВВЕДЕНИЕ
Программа «Учёт репетиторских занятий» помогает репетитору вести базу учеников, планировать расписание и отслеживать статистику занятий.
Основные возможности программы:
•	Добавление, редактирование и удаление учеников;
•	Создание расписания занятий;
•	Быстрая смена статуса занятия;
•	Защита от двойного бронирования времени;
•	Статистика по занятиям и часам;
•	Умный поиск учеников (в том числе с опечатками).
ГЛАВНАЯ СТРАНИЦА
При запуске программы открывается главная страница с тремя разделами:
•	Ученики — база данных всех учеников;
•	Расписание — календарь и список занятий;
•	Сводка — статистика по занятиям.
Чтобы перейти в раздел, кликните по нужной карточке.
Для возвращения на главную страницу, нажмите кнопку «← Назад» в левом верхнем углу любой другой страницы.
РАЗДЕЛ «УЧЕНИКИ»
На странице находятся:
•	Заголовок с количеством учеников;
•	Кнопка «+ Добавить ученика» — создание новой карточки;
•	Поле поиска — мгновенный поиск по ФИО, телефону, предмету;
•	Таблица со столбцами: ФИО, Телефон, Предмет, Класс/уровень, Заметки;
•	Кнопки «Редактировать» и «Удалить» — действия с выбранным учеником.
Открытие карточки ученика
Чтобы открыть карточку ученика, дважды кликните по его строке в таблице. Откроется форма с полной информацией об ученике.
Добавление ученика
1.	Нажмите «+ Добавить ученика»
2.	Заполните форму:
o	Фамилия (обязательно)
o	Имя (обязательно)
o	Отчество (необязательно)
o	Телефон (для связи)
o	Предмет (обязательно) — можно несколько через запятую, например: Математика, Физика
o	Класс / уровень — например, 9 класс или ЕГЭ
o	Заметки (любая дополнительная информация)
3.	Нажмите «Сохранить»
Подсказка: при вводе фамилии, имени или предмета программа предлагает варианты из уже существующих записей.
Редактирование ученика
1.	Кликните по строке ученика в таблице
2.	Нажмите «Редактировать»
3.	Измените нужные поля
4.	Нажмите «Сохранить изменения»
Удаление ученика
1.	Кликните по строке ученика
2.	Нажмите «Удалить»
3.	Подтвердите действие в диалоговом окне
Внимание: вместе с учеником удаляются все связанные с ним занятия.
Поиск учеников
•	Введите текст в поле «Поиск...»
•	Результаты обновляются мгновенно
•	Поиск работает по всем полям: ФИО, телефон, предмет, класс, заметки
•	Умный поиск: находит даже при опечатках (например, Иванов найдёт Иванов, Иван)
РАЗДЕЛ «РАСПИСАНИЕ»
На странице находятся:
•	Календарь слева — выбор даты
•	Таблица справа — список занятий на выбранную дату
•	Столбцы: Время, Ученик, Предмет, Статус
•	Кнопки: Добавить занятие, Редактировать, Удалить
•	Тумблер «День / Неделя» — переключение режима отображения
Переключение режимов отображения
В правой части заголовка таблицы расположен тумблер «День / Неделя». С его помощью можно переключать вид расписания:
•	День — показываются занятия только на выбранную дату
•	Неделя — показываются занятия на всю неделю, к которой относится выбранная дата
Чтобы переключить режим, просто кликните по тумблеру.
Работа с календарём
Календарь расположен в левой части страницы и позволяет быстро выбирать дату.
Переключение месяцев: используйте стрелки «<» и «>» в шапке календаря.
Быстрый переход между годами: кликните по названию месяца и года в шапке календаря (например, по надписи «НОЯБРЬ 2026»). Откроется режим выбора года — кликните по нужному году, чтобы сразу перейти к нему, не пролистывая месяцы по одному. Это удобно для просмотра расписания за прошлые или будущие периоды.
Открытие карточки занятия
Чтобы открыть карточку занятия для просмотра или редактирования, дважды кликните по его строке в таблице. Откроется форма с полной информацией о занятии, которую можно отредактировать и сохранить.
Добавление занятия
1.	Выберите дату в календаре
2.	Нажмите «+ Добавить занятие»
3.	Заполните форму:
o	Дата (по умолчанию выбрана дата из календаря)
o	Ученик (выберите из списка)
o	Предмет (выберите из списка, берётся из карточки ученика)
o	Время начала (например, 16:00)
o	Время окончания (например, 17:00)
o	Статус (по умолчанию «Запланировано»)
o	Заметки (необязательно)
4.	Нажмите «Сохранить»
Важно: программа не позволит создать два занятия одному ученику на пересекающееся время.
Редактирование занятия
1.	Кликните по строке занятия в таблице
2.	Нажмите «Редактировать»
3.	Внесите изменения
4.	Нажмите «Сохранить изменения»
Удаление занятия
1.	Кликните по строке занятия
2.	Нажмите «Удалить»
3.	Подтвердите действие
Быстрая смена статуса (правый клик)
Самый быстрый способ изменить статус занятия:
1.	Правой кнопкой мыши кликните по ячейке в столбце «Статус»
2.	В появившемся меню выберите нужный статус
3.	Статус изменится мгновенно и сохранится в базе
Текущий статус отмечен галочкой и выделен жирным шрифтом.
Статусы занятий
Запланировано — занятие назначено, но ещё не прошло Проведено — занятие успешно состоялось Отменено — занятие отменено Перенесено — занятие перенесено на другую дату/время
РАЗДЕЛ «СВОДКА»
На странице находятся:
•	Фильтры периода: Этот месяц, Прошлый, Этот год, Всё время, Произвольный период
•	Карточки статистики:
o	Всего занятий — общее количество
o	Отработано часов — суммарное время проведённых занятий
o	Пропущено / Отменено — количество таких занятий
o	Активный день — день с наибольшим количеством занятий
•	Таблица по ученикам: Ученик, Проведено, Пропущено, Часы
Открытие карточки ученика из сводки
Чтобы открыть карточку ученика из раздела «Сводка», дважды кликните по его строке в таблице. Откроется форма с полной информацией об ученике, которую можно просмотреть и отредактировать.
Фильтрация по периоду
Можно фильтровать по периодам:
•	Этот месяц — статистика за текущий месяц
•	Прошлый — статистика за предыдущий месяц
•	Этот год — статистика с 1 января текущего года
•	Всё время — вся история занятий
•	Произвольный период — укажите даты вручную (с ... по ...)
На странице есть таблица по ученикам, где:
•	Ученик — ФИО ученика
•	Проведено — количество состоявшихся занятий
•	Пропущено — количество отменённых/перенесённых занятий
•	Часы — суммарное время проведённых занятий
